## Guia Prático: Boas Práticas e Arquitetura de APIs RESTful Java e Spring Boot

## Objetivo
Capacitar estudantes de tecnologia e desenvolvedores backend a estruturar, documentar e versionar APIs limpas, seguras e escaláveis utilizando o ecossistema Java e Spring Boot.

## Público-alvo
Estudantes de Engenharia de Software, programadores júniores e entusiastas de desenvolvimento backend.

## Pré-requisitos
- Conhecimento básico da linguagem Java e de programação orientada a objetos.
- Ambiente de desenvolvimento configurado (IDE, JDK e gestor de dependências como Maven ou Gradle).

## Estrutura
- `/docs`: Contém os módulos teóricos e práticos do guia.
- `/exemplos`: Contém os exemplos de código comentados.
- `aprendizados.md`: Relatório de reflexão e conceitos aplicados.
- `conflito-resolvido.md`: Documentação e registo de conflito controlado no Git.

## Como navegar
Comece por ler o ficheiro principal e avance sequencialmente pelos módulos localizados na pasta `/docs` (`01-introducao.md` até `04-referencias.md`), consultando a pasta `/exemplos` para a vertente prática.
